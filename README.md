# Projeto Prático em Grupo
Realizamos este trabalho como parte de um projeto prático em grupo. Para organizar o desenvolvimento, dividimos a equipe em duas partes: Infraestrutura e HTML/CSS/JavaScript.

# SITE
Desenvolvemos um site voltado para depilação a laser, com o objetivo de apresentar os serviços e facilitar a consulta dos usuários.

As principais funcionalidades desenvolvidas foram:

**Calculadora de preços**, permitindo consultar os valores de acordo com a área escolhida;

**Lista de áreas de depilação**, apresentando as regiões do corpo em que o procedimento pode ser realizado.

# ÁREAS QUE PODEM SER DEPILADAS
O site apresenta as seguintes áreas:
* Axilas;
* Virilha completa;
* Pernas inteiras;
* Buço / rosto;
* Braços completos;
* Linha alba (barriga);
* Barba completa;
* Peitoral + abdômen;
* Costas completas;
* Faixa de barba / pescoço;
* Ombros;
* Axilas Masculinas.
# COMO FOI DESENVOLVIDO?
Para a realização do projeto, utilizamos o VirtualBox e o Visual Studio Code (VS Code).
O desenvolvimento foi realizado de forma colaborativa, com cada parte da equipe contribuindo em sua respectiva área. Dessa forma, conseguimos integrar a infraestrutura com o desenvolvimento do site, colocando em prática os conhecimentos adquiridos durante o curso.
